## 📖 About

**Database Systems Foundations** is a practical learning repository containing my study, practice, and implementation work related to **Database Management Systems (DBMS), SQL, relational databases, and data analysis**.

This repository brings together the concepts and SQL queries I practiced while studying database systems. Instead of keeping everything limited to theoretical notes, I organized my learning into **SQL query files, database exercises, datasets, SQL projects, and database design files**.

The repository covers fundamental SQL operations as well as more advanced query concepts, including **joins, subqueries, table-related queries, foreign key relationships, cascading foreign keys, and database constraints**.

It also includes practical work from the **Data Analysis Using SQL** course, where SQL was applied to real-world datasets and analytical problems. These exercises provided hands-on experience with using SQL not only for managing data, but also for exploring, filtering, aggregating, and analyzing datasets.

A dedicated **e-commerce database project** is also included, providing practical experience in designing and working with a database around a real-world application scenario.

The repository represents my journey through the foundations of database systems — from understanding relational concepts and SQL syntax to solving practical problems and building database projects.
